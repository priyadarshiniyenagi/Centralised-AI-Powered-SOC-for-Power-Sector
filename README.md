# Centralized AI-Powered Security Operations Center for Power Sector

## Project Description

This project develops a centralized AI-powered Security Operations Center (SOC)
for monitoring and detecting cybersecurity attacks in power-sector OT/SCADA
environments.

## Datasets

SANDI-2024:
- IEC 104
- IEC 61850

## Main Components

1. Dataset Profiling
2. Data Preprocessing
3. Feature Engineering
4. AI/ML Attack Detection
5. Event Correlation
6. Alert Prioritization
7. SOC Dashboard
